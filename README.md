# Excel-Based Bill Computation System

## Project Overview

Developed an Excel-based billing and computation system to automate weekly food bill calculations using spreadsheet formulas, lookup functions and named ranges.

The workbook consists of two interconnected worksheets: an item database containing food items and their corresponding prices, and a weekly computation sheet that uses this information to calculate bills based on quantities entered.

The system reduces repetitive manual calculations and makes the billing process more structured and efficient.

## Key Features

- **Centralised Item Database:** Maintains a structured list of food items and their corresponding prices.
- **Automated Price Retrieval:** Uses VLOOKUP to retrieve item prices from the item database based on selected food items.
- **Quantity-Based Computation:** Calculates item-wise costs using the quantities entered in the weekly computation sheet.
- **Conditional Calculations:** Uses IF and COUNTA functions to perform calculations only when relevant entries are present.
- **SUMIF-Based Calculations:** Applies conditional summation to consolidate amounts based on specified criteria.
- **Named Ranges:** Uses named ranges to make formulas more readable, organised and easier to manage.
- **Automated Bill Calculations:** Integrates multiple formulas to calculate weekly billing totals.

## Workbook Structure

The workbook consists of two worksheets:

### 1. Item Database

- Contains the names of all food items.
- Stores the corresponding prices for each item.
- Acts as the central reference sheet for price retrieval.

### 2. Weekly Computation Sheet

- Accepts food item selections and their respective quantities.
- Retrieves corresponding prices using VLOOKUP.
- Calculates item-wise amounts and applicable charges.
- Uses conditional formulas to handle specific billing requirements.
- Computes weekly totals through interconnected formulas.
